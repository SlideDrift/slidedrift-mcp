# SlideDrift

Use the `slidedrift` MCP server when the user wants LinkedIn posts or carousels made from their own material (a link, notes or an idea), wants to edit an existing SlideDrift carousel, or wants to export or schedule LinkedIn content. The first call opens a browser to sign in to SlideDrift (OAuth, no API key).

SlideDrift shows the credit cost before it generates or exports and waits for approval: show that quote to the user and never approve for them. Scheduling needs a separate approval. Full guide: `skills/slidedrift/SKILL.md`.
